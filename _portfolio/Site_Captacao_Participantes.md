Landing page pública criada para apresentar uma tecnologia experimental de interação visual em tempo real e captar voluntários para participação em testes. O site traduz um projeto técnico de pesquisa para uma linguagem acessível, clara e responsável.

## Problema

Projetos de pesquisa com participantes precisam comunicar objetivo, procedimento e condições de participação sem excesso de jargão técnico. A página também deve evitar promessas médicas, diagnósticas ou terapêuticas, deixando claro que se trata de uma avaliação experimental de tecnologia.

## Solução

- Site em React com Vite, preparado para deploy na Vercel.
- Texto público focado em interação visual, participação voluntária e privacidade.
- Chamada para inscrição por formulário.
- Estrutura para explicar o teste como uma experiência simples, parecida com um pequeno jogo.
- Conteúdo planejado para captar participantes sem expor detalhes internos do pipeline científico.

## Impacto

O projeto conecta pesquisa, produto e comunicação. Além de apoiar a coleta de dados do mestrado, demonstra capacidade de transformar uma pesquisa técnica em uma interface pública compreensível para voluntários, parceiros e pessoas não especialistas.
